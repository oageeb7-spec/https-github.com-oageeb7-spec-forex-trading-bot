How the agency works

STEP 1

Give an agent a job

Open any agent and describe the task: paste code to review, a product to position, data to analyze. It works in its own voice and process, and hands back the deliverable. Keep going in the chat to refine it.

STEP 2

Run a team

Press Add to team on several agents, open Review & install and give the team one job. Each member takes a turn and builds on the work before it.

STEP 3

Install them

To use agents inside Claude Code, copy the team's install script and run it. It downloads each agent file into Claude Code's agent folder.

mkdir -p ~/.claude/agents
curl -fsSL -o ~/.claude/agents/<agent>.md \
  https://raw.githubusercontent.com/msitarzewski/agency-agents/main/<path>
STEP 4

Activate in a session

Ask for the agent by name. Other tools (Cursor, Codex, Gemini CLI) are covered by the repo's own installer.

"Activate Backend Architect mode and
 design the API for my booking app."

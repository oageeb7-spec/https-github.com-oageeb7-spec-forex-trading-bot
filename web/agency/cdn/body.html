Autopilot

Set a goal. The agency runs itself.

The Agents Orchestrator plans the work and picks the specialists. Each one delivers their part in turn, building on the last. You get a launch kit: the finished assets plus the exact steps to take them to market and get paid.

The agents do the work; you launch it. They can't take payments, post, send email or spend money on their own, so nothing goes out without you. Revenue figures are estimates with stated assumptions, not promises.

How it works

From brief to deliverable

Each agent runs on Claude with its full brief as instructions, so you get the specialist's process and voice, not a generic answer.

01

Give an agent a job

Open any agent and describe the task: paste code to review, a product to position, data to analyze. You get the deliverable back, and you can keep refining it in the chat.

02

Run a team

Press Add to team on several agents, open Review & install and give the team one job. Each member takes a turn and builds on the work before it.

03

Install them

To use agents inside Claude Code, copy the team's install script and run it.

mkdir -p ~/.claude/agents
curl -fsSL -o ~/.claude/agents/<agent>.md \
  https://raw.githubusercontent.com/msitarzewski/agency-agents/main/<path>
04

Activate in a session

Ask for the agent by name. Cursor, Codex and Gemini CLI are covered by the repo's own installer.

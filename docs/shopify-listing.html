OS Trading AI is a self-hosted research system for forex strategies. A team of AI agents finds trading ideas in real sources, turns them into testable strategies, backtests them on real OS AI price data, and paper-trades the ones you approve — all shown in a live dashboard.

What it does

  • Research agents search arXiv papers, GitHub repositories and web articles (plus YouTube with your own key), read them, and extract the trading rule each one describes.
  • Claude-powered analysis decides whether a source describes a rule that can be tested, which currency pairs it targets and which settings it uses. A free keyword mode works without an Anthropic key.
  • Backtesting lab tests 10 variants of every strategy on about a year of hourly OS AI data for forex, gold, Bitcoin and meme coins, with typical spreads.
  • Five-check robustness sieve: out-of-sample results, settings changed ±20%, a second currency pair, triple spread costs, and month-by-month consistency.
  • Paper trading on live OS AI prices for 21 trading days before anything is proposed for live.
  • Dashboard with ten screens, including a 3D room showing each agent at work, a knowledge base of trading concepts, and a cost tracker.

What you get

  • The full source code as a ZIP download (Node.js)
  • Setup instructions in the included README
  • A demo mode that runs without any API keys

Requirements

  • A computer or server with Node.js 18 or newer
  • Optional: an Anthropic API key for Claude analysis (billed by Anthropic, capped by a budget you set)

Please note

OS Trading AI is a research and education tool. It does not place real orders and makes no promise of profits. Backtested and paper-trading results do not guarantee future performance. Nothing in this product is financial advice. Trading foreign exchange carries a high level of risk.
